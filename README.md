# Multi Twitch — website

Watch several Twitch streams at once in the browser, with the chat.

**Open it:** <https://maximecoutantin.github.io/multitwitch-web/> (password-locked).

This repository only holds the published page: one encrypted `index.html` served by GitHub Pages.
Nothing here is meant to be edited by hand — it's rebuilt from the private **multitwitch** repository,
which also holds the Android app and the Chrome extension.

For the best experience in Chrome, install the **Multi Twitch player** extension from the site's
Settings → Player for Chrome (low delay, no unwanted pauses, ad countdown, small window).
